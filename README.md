# 정보통신산업진흥원 2026 예산 생태계 MAP

과학기술정보통신부의 2026년 예산 및 기금운용계획 사업설명자료 1~8권에서 사업시행주체로 정보통신산업진흥원(NIPA)이 명시된 사업을 선별해 구성한 단일 HTML 대시보드입니다.

## 바로 보기

- GitHub Pages 진입 파일: `index.html`
- 원본 결과 파일: `nipa-ai-budget-ecosystem-dashboard.html`
- 정규화 데이터: `nipa-ai-budget-projects.json`
- 검증 결과: `nipa-budget-verification.json`

`index.html`은 별도 서버나 번들러 없이 브라우저에서 바로 실행됩니다.

## 제공 화면

- 예산 현황판: 사업 검색, 레이어·조직 필터, 예산순 정렬
- 레이어 매핑: AI인프라, AI반도체, AI모델, 지역AX, 피지컬AI, 글로벌 이니셔티브, AI생태계, 산업전략, 기관운영비
- 과기정통부 소관 현황: 소관 과·팀이 다른 경우 내역사업 단위로 분리
- NIPA 본부별 사업현황: 내부 현황조사 기준 담당 본부 및 예산 분리
- 엑셀 자료관리: 현재 필터의 사업·항목 선택 다운로드, 전체 DB 다운로드, 신규 사업 양식 업로드
- 사업 상세: 레이어, 사업코드/회계, 소관 본부, 예산, 주요내용, 추진방향, 원문 근거

## 엑셀 자료관리

내보내기와 신규 사업 입력 양식은 `사업명, 세부사업명, 사업코드, 회계, 레이어, 과기정통부 소관, NIPA 본부, 2026년 예산(백만원), 개요, 주요내용, 추진방향`으로 구성됩니다. 예산 근거, 구분, 원문, 관리 항목은 제외했습니다.

신규 사업 양식에서 사업명과 세부사업명이 다르면 내역사업 카드로 등록됩니다. 업로드 자료는 파일 자체를 변경하지 않고 현재 브라우저의 로컬 저장소에 보존되며, 전체 DB 엑셀 다운로드로 다시 저장할 수 있습니다.

## 로컬 실행

```bash
npm install
npm run serve
```

생성 스크립트를 다시 실행하려면 로컬 작업용 원문 추출 파일과 검증 DB가 필요합니다.

```bash
npm run build
```

원본 HWPX, 내부 본부 조사 엑셀, 중간 추출물은 공개 저장소에 포함하지 않도록 `.gitignore`로 제외했습니다. 이미 생성된 `index.html`은 이러한 로컬 입력 없이도 사용할 수 있습니다.

## 데이터 기준

- 금액 단위: 백만원
- 포함 기준: 사업 머리부의 사업시행주체에 정보통신산업진흥원이 명시된 경우
- 공동 시행 사업: NIPA 담당 내역 및 지원금액만 표시
- 내역 전용 카드: 해당 내역의 사업목적·내용만 요약하되 모사업 전체 내역표는 유지
- 레이어 분류: 기술 키워드보다 최종 정책목적을 우선
