# 정보통신산업진흥원 2026 예산 생태계 MAP

과학기술정보통신부의 2026년 예산 및 기금운용계획 사업설명자료 1~8권에서 사업시행주체로 정보통신산업진흥원(NIPA)이 명시된 사업을 선별해 구성한 단일 HTML 대시보드입니다.

## 바로 보기

- GitHub Pages 진입 파일: `index.html`
- 원본 결과 파일: `nipa-ai-budget-ecosystem-dashboard.html`
- 정규화 데이터: `nipa-ai-budget-projects.json`
- 검증 결과: `nipa-budget-verification.json`

`index.html`은 별도 서버나 번들러 없이 브라우저에서 바로 실행됩니다.

## 제공 화면

- 예산 현황판: 사업 검색, 레이어·조직 필터, 예산순 정렬
- 레이어 매핑: AI인프라, AI반도체, AI모델, 지역AX, 피지컬AI, 글로벌 이니셔티브, AI생태계, 산업전략, 기관운영비
- 과기정통부 소관 현황: 소관 과·팀이 다른 경우 내역사업 단위로 분리
- NIPA 본부별 사업현황: 내부 현황조사 기준 담당 본부 및 예산 분리
- DB 관리: 전용 필터의 사업·항목 선택 다운로드, 전체 DB 다운로드, 신규 사업 추가 및 기존 사업 수정
- 사업 상세: 레이어, 사업코드/회계, 소관 본부, 예산, 주요내용, 추진방향, 원문 근거

## DB 관리

내보내기 화면의 `필터 적용하기` 팝업에서 사업명·사업코드, 레이어, 회계, 과기정통부 소관, NIPA 본부를 독립적으로 선택할 수 있습니다. 내보내기와 신규 사업 입력 양식은 `사업명, 세부사업명, 사업코드, 회계, 레이어, 과기정통부 소관, NIPA 본부, 2026년 예산(백만원), 개요, 주요내용, 추진방향`으로 구성됩니다. 예산 근거, 구분, 원문, 관리 항목은 제외했습니다.

신규 사업 양식에서 사업명과 세부사업명이 다르면 내역사업 카드로 등록됩니다. 업로드 자료는 파일 자체를 변경하지 않고 현재 브라우저의 로컬 저장소에 보존되며, 전체 DB 엑셀 다운로드로 다시 저장할 수 있습니다.

기존 사업은 전체 DB 엑셀을 내려받아 수정한 뒤 `기존 사업 수정`에 업로드할 수 있습니다. `사업코드 + 세부사업명 + 사업명`을 식별값으로 사용하며, 일치하는 카드의 회계·레이어·소관·본부·예산·개요·주요내용·추진방향을 수정합니다. 사업명 자체를 바꾸려면 먼저 기존 식별값으로 일치시켜야 하므로 현재 수정 기능에서는 사업명과 세부사업명을 변경하지 않습니다.

## 오프라인 Excel 버전

`NIPA_2026_예산_DB_관리.xlsx`는 인터넷 연결 없이 사용할 수 있는 별도 Excel 업무 버전입니다. 대시보드, 사업 DB, 레이어 현황, 본부별 현황, 신규입력 안내 시트로 구성됩니다. 사업 DB의 기존 행을 직접 수정하거나 표 하단 빈 행에 신규 사업을 추가하면 요약 수식이 갱신됩니다.

```bash
npm run build:excel
```

Excel 버전은 셀 편집·표 필터·드롭다운·조건부 서식에 초점을 두며, HTML의 팝업 카드와 조직도 탐색을 그대로 재현하지는 않습니다. 수정한 사업 DB 시트는 HTML 대시보드의 DB 관리 탭에 다시 업로드할 수 있습니다.

### Excel 업무 앱

`NIPA_2026_예산_업무앱.xlsm`은 HTML의 탐색 경험을 Excel 안에서 최대한 살린 매크로 기반 업무용 버전입니다.

- 카드형 홈 화면과 화면 이동 버튼
- 검색어·레이어·NIPA 본부 기반 사업 탐색
- 선택 사업의 개요·주요내용·추진방향을 Excel UserForm 팝업 카드로 표시
- 팝업 카드에서 기존 사업 수정 UserForm으로 이동
- 신규 사업 등록 UserForm 및 사업 DB 저장
- 레이어·본부별 현황에서 선택 항목의 사업 탐색
- 원본 사업 DB 직접 편집

파일을 열 때 Excel 상단의 `콘텐츠 사용`을 눌러 매크로 실행을 허용해야 합니다. 생성 스크립트를 다시 실행하려면 Excel 보안 센터의 `VBA 프로젝트 개체 모델에 안전하게 액세스할 수 있음`도 켜야 합니다.

```bash
npm run build:excel-app
```

## 로컬 실행

```bash
npm install
npm run serve
```

생성 스크립트를 다시 실행하려면 로컬 작업용 원문 추출 파일과 검증 DB가 필요합니다.

```bash
npm run build
```

원본 HWPX, 내부 본부 조사 엑셀, 중간 추출물은 공개 저장소에 포함하지 않도록 `.gitignore`로 제외했습니다. 이미 생성된 `index.html`은 이러한 로컬 입력 없이도 사용할 수 있습니다.
